# Archetipo Composizionale: CTE Pipeline & Parallel Stitching

## Descrizione del Pattern

Scomporre un problema analitico multi-step in diverse CTE non ricorsive definite in parallelo o in sequenza (`WITH a AS (...), b AS (...)`), che vengono poi incrociate tramite `JOIN` o aggregate. Pattern isolato da BEAVER ("Multiple CTEs + JOIN") e da Spider 2.0 ("sequential CTEs": la CTE usata come pipeline di passi intermedi, non come semplice alias). (Zero-Data: il modello deve inventare uno schema ampio e articolato con molte tabelle di distrazione, delle quali solo alcune rilevanti, e costruire insiemi derivati intermedi tramite `WITH` per poi combinarli.)

Esempio di composizione SQL (enterprise — ricava le top-3 regioni per fatturato e ne aggrega il ricavo per categoria):

```sql
WITH regional_sales AS (
  SELECT r.region_id, SUM(o.amount) AS total
  FROM orders o
  JOIN regions r ON o.region_id = r.id
  GROUP BY r.region_id
),
top_regions AS (
  SELECT region_id, total
  FROM regional_sales
  ORDER BY total DESC
  LIMIT 3
)
SELECT c.category_name, SUM(o.amount) AS category_revenue
FROM orders o
JOIN top_regions tr ON o.region_id = tr.region_id
JOIN categories c ON o.category_id = c.id
GROUP BY c.category_name;
```
