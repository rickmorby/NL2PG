# Archetipo Composizionale: Nested-Complex Triple (JOIN + Subquery + Set Operation)

## Descrizione del Pattern

Combinare simultaneamente un `JOIN`, una subquery annidata e un operatore insiemistico (`UNION` / `INTERSECT` / `EXCEPT`) applicato sopra i risultati di subquery: la classe "nested complex" isolata da Spider e dal classificatore DIN-SQL come pattern di difficoltà *Hard/Extra-Hard*. (Zero-Data: il modello deve inventare uno schema con chiavi esterne implicite e molte tabelle di distrazione, e risolvere la richiesta unendo relazioni, filtrando tramite subquery annidata e fondendo due insiemi di risultato con un operatore insiemistico.)

Esempio di composizione SQL (enterprise — dipendenti HQ sopra la media stipendi, esclusi i contractor standard):

```sql
SELECT e.name
FROM employees e
JOIN departments d ON e.dept_id = d.id
WHERE d.location = 'HQ'
  AND e.salary > (SELECT AVG(salary) FROM employees)
EXCEPT
SELECT c.name
FROM contractors c
WHERE c.clearance = 'standard';
```
