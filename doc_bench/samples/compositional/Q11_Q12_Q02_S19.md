# Archetipo Composizionale: Relativized Aggregate Comparison (row/group vs baseline aggregate)

## Descrizione del Pattern

Confrontare un valore di riga (o un aggregato per gruppo) contro un aggregato di base calcolato su tutta la tabella o sullo stesso gruppo, tramite subquery scalare o correlata. Pattern canonico e ampiamente documentato (es. Wikipedia "Correlated subquery": *"employees whose salary is above average for their department"*; tutorial ufficiali PostgreSQL: *"films longer than the average for their rating"*; W3Schools: *"Higher Than Average"*). Ricorrente nelle query analitiche reali ("sopra la media del reparto", "sopra la media aziendale"). Puo' impiegare sia una subquery correlata (confronto per-gruppo, `WHERE col > (SELECT AVG(...) WHERE group = outer.group)`) sia una subquery scalare non correlata (confronto contro la media globale, `WHERE col > (SELECT AVG(...) FROM tabella)`). (Zero-Data: il modello deve inventare un dominio con entità raggruppabili e calcolare un aggregato di base da usare come riferimento nel filtro.)

Esempio di composizione SQL (enterprise — dipendenti con stipendio sopra la media del proprio dipartimento):

```sql
SELECT name, salary
FROM employees e
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
    WHERE department = e.department
);
```

Variante a media globale (subquery scalare non correlata):

```sql
SELECT product_name, price
FROM products
WHERE price > (SELECT AVG(price) FROM products);
```
