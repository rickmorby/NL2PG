# Archetipo Composizionale: Statistical Window Analytics (NTILE / STDDEV / CORR / VARIANCE)

## Descrizione del Pattern

Applicare aggregati statistici (deviazione standard, varianza, correlazione, funzioni di quartile/percentile) in un contesto a finestra o di partizionamento, spesso combinati con `GROUP BY` per altre metriche. Pattern isolato esplicitamente da Spider 2.0 ("Advanced Data Calculation: Window functions + Aggregation/Math: NTILE, STDDEV, CORR") e da BEAVER come calcolo analitico avanzato su raggruppamenti complessi. Distinto dalle finestre puramente ordinali (RANK/ROW_NUMBER) e dai pattern temporali. (Zero-Data: il modello deve inventare uno schema analitico multidimensionale, e calcolare metriche statistiche (volatilità, correlazione) su dati raggruppati tramite funzioni finestra.)

Esempio di composizione SQL (enterprise — quartile di volatilità e correlazione prezzo-unità per regione/prodotto):

```sql
SELECT region,
       product_line,
       NTILE(4) OVER (PARTITION BY region ORDER BY STDDEV(sales) DESC) AS volatility_quartile,
       CORR(price, units) OVER (PARTITION BY region) AS price_units_corr,
       AVG(sales) AS avg_sales
FROM monthly_sales
GROUP BY region, product_line;
```
